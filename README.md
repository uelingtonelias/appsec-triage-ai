# Triage-AI

AI-powered Application Security Triage Agent.

## Features

- Semgrep JSON parsing
- Vulnerability triage
- False positive reduction
- Repository context analysis
- Multi-language support
- Framework detection
- Ollama integration
- Developer remediation recommendations

## Supported Languages

- Python
- Java
- C#
- JavaScript
- TypeScript
- Go
- PHP

## Usage

python main.py \
  --report semgrep.json \
  --repo ./repository
